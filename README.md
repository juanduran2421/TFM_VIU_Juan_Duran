# 🏨 Predicción de Cancelaciones en Reservas Hoteleras con Machine Learning

Este repositorio contiene el código, desarrollo analítico y los resultados de mi **Trabajo de Fin de Máster (TFM) en Big Data y Ciencia de Datos**. 

El objetivo principal de este proyecto es desarrollar modelos predictivos explicables para anticipar el riesgo de cancelación de reservas hoteleras a nivel transaccional, optimizando las estrategias de *Revenue Management* y *Overbooking* dinámico.

## 📊 Descripción del Proyecto

El análisis aborda la naturaleza del inventario hotelero perecedero utilizando un dataset de más de 118,000 registros transaccionales provenientes de un PMS real en Portugal.
